# Minzoni Codice Vivo

Presentazione interattiva per le visite di orientamento del percorso Sistemi Informativi Aziendali del Minzoni di Giugliano.

[Apri Codice Vivo](https://antoniorasulo89.github.io/minzoni-codice-vivo/)

Premi **Avvia il percorso** per la visita guidata da circa dieci minuti. Dal menu **Sfide** puoi scegliere una delle sei attività. Per usare la presentazione offline, scarica il file HTML e aprilo nel browser.
